```python
# Exemplo: com docstring profissional
def tfidf_cosine_similarity(text_a: str, text_b: str) -> float:
    """Compute TF-IDF-weighted cosine similarity between two texts.
    
    Implements the classical information retrieval approach combining
    TF-IDF term weighting with cosine similarity normalization...
    
    Args:
        text_a (str): First document text
        text_b (str): Second document text
        
    Returns:
        float: Similarity score in [0, 1]
    
    Time Complexity: O(n + m) 
    Space Complexity: O(n + m)
    
    Example:
        >>> score = tfidf_cosine_similarity("hello world", "hello earth")
        >>> assert 0.5 < score <= 1.0
    
    Strengths:
        - Robust to word order variations
        - Effective for semantic similarity
        
    Limitations:
        - Bag-of-words loses word order
        - Sensitive to term weighting
    """
    tokens_a = tokenize(text_a)
    tokens_b = tokenize(text_b)
    vec_a = _build_tfidf_vector(tokens_a, all_tokens)
    vec_b = _build_tfidf_vector(tokens_b, all_tokens)
    return _cosine_similarity(vec_a, vec_b)
```

**Benefícios:**
- ✅ Autoexplicativo
- ✅ IDE mostra help
- ✅ Documenta complexidade
- ✅ Exemplos prontos
- ✅ Padrão profissional (Google-style)
